# Lab 2 Rubric — Linux Administration and Deploying a Web App to EC2 (10 points)

- [ ] Deployment script installs and starts the web server correctly, verified reachable over HTTP (3 pts)
- [ ] Script is wrapped in a systemd unit that is enabled (survives a reboot, not just started once) (2 pts)
- [ ] Security group restricts SSH appropriately while allowing HTTP (2 pts)
- [ ] Work was done as a dedicated sudo-enabled non-root user, not the default `ec2-user` directly (2 pts)
- [ ] README explains the deployment steps (1 pt)
